## ⚙️ Build 

1. clone this repo  
```bash
$ git clone https://github.com/peter910820/socketio-chatroom.git
```  
2. install package  
```bash
$ pip install -r requirements.txt
```  
3. into repo and run server.  
```bash
$ cd ./socketio-chatroom
$ python3 app.py
```  
4. use form to get your github-profile-card
